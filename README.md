🎵 Hip-Hop Music Player
========================

A feature-rich web-based music player featuring tracks from **Lil Durk**, **Lil Baby**, and **NBA YoungBoy**.

## Features

✅ **Play/Pause Controls** - Start and stop playback  
✅ **Next/Previous Navigation** - Navigate through songs  
✅ **Shuffle Mode** - Randomize song order  
✅ **Repeat Modes** - Repeat all songs or single song  
✅ **Volume Control** - Adjust audio volume  
✅ **Progress Bar** - Seek to any point in the song  
✅ **Playlist Display** - View and select from all songs  
✅ **Now Playing Info** - Display current song details  
✅ **Album Artwork** - Show album cover images  
✅ **Time Display** - Current time and total duration  
✅ **Responsive Design** - Works on desktop and mobile  
✅ **Keyboard Shortcuts** - Control with keyboard  

## Artist Collection

The player includes hits from:

- **Lil Durk** - "Finesse", "The Code"
- **Lil Baby** - "Back Again", "Drip Too Hard"
- **NBA YoungBoy** - "Kick In The Door", "Outside Today", "Top"
- **Collaborations** - "Cash", and more

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Play/Pause |
| `→` | Next Song |
| `←` | Previous Song |

## How to Use

1. Open `index.html` in your web browser
2. Click the play button to start music
3. Use the controls to navigate and adjust settings
4. Click on any song in the playlist to play it
5. Use the volume slider to adjust sound level
6. Enable shuffle or repeat modes as desired

## Features Breakdown

### Player Controls
- **Play/Pause**: Toggle playback status
- **Previous**: Go to the previous song
- **Next**: Go to the next song
- **Shuffle**: Randomize playback order
- **Repeat**: Cycle between no repeat, repeat all, and repeat one

### Playlist Management
- Interactive playlist with all songs
- Click to select and play any song
- Active song highlighting
- Smooth scrolling to current song

### Visual Design
- Modern dark theme with gradient background
- Album artwork with floating animation
- Color-coded controls (red and gold theme)
- Smooth transitions and hover effects
- Fully responsive for all screen sizes

## Audio Sources

The player uses placeholder audio tracks. To use real music:
1. Replace the `url` in the `songs` array with actual audio file URLs
2. Update album artwork URLs in the `image` field
3. Ensure audio files are accessible online or hosted locally
